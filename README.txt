How to publish on GitHub Pages
1. Create or open your GitHub Pages repository.
2. Upload index.html to the repository root.
3. Commit the change.
4. In GitHub Settings > Pages, publish from your main branch/root folder if not already enabled.
5. Your existing GitHub Pages URL can then display this portfolio.
